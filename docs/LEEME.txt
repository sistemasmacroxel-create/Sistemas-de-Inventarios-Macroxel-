Uso:
1. Abra index.html en un navegador moderno.
2. Para uso publicado, suba completa la carpeta "docs" al servidor/GitHub Pages.
3. No cambie los nombres de los archivos sin actualizar las referencias de index.html.

Nota técnica:
La versión web utiliza los mecanismos de almacenamiento del navegador cuando Electron/SQLite no está disponible. Algunas funciones exclusivas del instalador de escritorio (por ejemplo, integraciones nativas de Electron) sólo estarán disponibles en la versión instalada.


GitHub Pages: configura la fuente de publicación como rama principal /docs.
Para reemplazar o eliminar el sistema web, trabaja únicamente con la carpeta docs.
