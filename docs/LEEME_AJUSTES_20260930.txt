AJUSTE EAN-13 DE PRÉSTAMOS 2026-09-30
- Al registrar un préstamo de Servicio quirúrgico se genera un EAN-13 interno único con prefijo Macroxel 299 y dígito de control válido.
- El EAN se guarda en todas las líneas del préstamo y permanece disponible después de ajustar, recuperar o finalizar.
- Se abre una etiqueta imprimible al crear el préstamo con establecimiento, paciente, edad, sexo, fecha, folio, servicio y código de barras.
- Historial de servicios: muestra EAN, permite reimprimir etiqueta y tiene campo específico para escanear préstamos.
- Salidas internas: el buscador de productos reconoce un EAN de préstamo al escanearlo y abre la ficha del préstamo antes de tratarlo como producto.
- La ficha escaneada muestra paciente, edad, sexo, fecha, folio, servicio, estado y cantidades; si el préstamo sigue activo permite Ajustar y Finalizar.
